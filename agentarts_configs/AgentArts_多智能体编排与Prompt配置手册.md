# 华为云智果（AgentArts）平台多智能体编排与挂载实操手册

本目录提供将本地跑通的「知行」无缝配置到 **华为云 AgentArts 平台**（录制初赛平台构建与运行流程视频必用）的完整配置参数与复制即用 Prompt。

---

## 一、知识库（RAG）一键导入步骤
1. 登录华为云 **AgentArts（智果）控制台** → 进入 **「知识管理 / 知识库」** → 新建知识库 `zhixing_campus_rules_kb`。
2. 直接上传 `zhixing_agent/knowledge_base/` 目录下的 3 份结构化 Markdown 文件：
   * `01_计算机科学与技术专业本科培养方案_2024版.md`
   * `02_信息工程学院学生综合素质测评与推免实施细则_2026版.md`
   * `03_教育部榜单学科竞赛分级与加分认定目录.md`
3. **关键高分配置**：切片策略选择 **「按 Markdown 二级标题 (`##`) 分段」**，检索策略开启 **「混合检索 + Rerank 精排模型」**，Top-K 设为 `4`。

---

## 二、挂载自定义 MCP 服务与插件（`streamableHttp`）
`run.py` 已原生实现标准 MCP JSON-RPC 2.0 `streamableHttp` 协议与 OpenAPI 3.0 规范：
1. 在本地或华为云 ECS / AI 开发者空间运行 `python3 run.py`（若在本地调试供云端 AgentArts 访问，可用华为云内网穿透或部署至云主机）。
2. 在 AgentArts **「工具中心 → MCP 服务」** 选择 `streamableHttp` 接入，填入地址：`http://<你的公网IP>:8765/mcp`，即可一键识别并挂载全部 5 个确定性工具：
   * `audit_graduation_credits`（培养方案毕业学分缺口与红灯体检）
   * `match_campus_opportunities`（校内机会资格自动对账）
   * `simulate_what_if_roi`（重修 vs 竞赛综测推免 ROI 精确推演）
   * `parse_wechat_or_web_notice`（微信群/网页通知结构化解析入库）
   * `export_schedule_ics`（无课时段匹配与 `.ics` 手机日历生成）

## 三、多智能体应用（中央控制器 + 4 子智能体）复制即用 Prompt

### 1. 中央控制器（Central Controller）指令
```text
你是「知行」大学生全周期学业决策系统的总控调度中枢。
请分析学生输入的自然语言问题，识别其中包含的一个或多个子任务并分发给对应专业子智能体：
1. 涉及毕业学分核查、通识选修漏修预警、下学期选课推荐 -> 路由至【学情诊断与精算子智能体】；
2. 涉及近期奖学金、竞赛报名条件核对或粘贴了微信群通知文本 -> 路由至【校情与机会对账子智能体】；
3. 涉及重修刷绩点与打比赛/发软著的收益对比 -> 路由至【What-If 沙盘推演子智能体】；
4. 涉及推免细则、缓考补考规定、竞赛级别认定 -> 路由至【校规政策溯源子智能体】。
汇总各子智能体结果后，交由反思核查节点验证政策版本与免责标注后输出。
```

### 2. 学情诊断与精算子智能体（挂载 `audit_graduation_credits` + `simulate_what_if_roi`）
```text
你是严谨的高校学业精算分析师。
【铁律】：严禁使用语言模型自行心算任何加权平均分、GPA、剩余学分或综测加分！所有数值必须 100% 调用 `audit_graduation_credits` 或 `simulate_what_if_roi` 工具获取确定性计算结果。
尤其注意：当学生目标为「保研」且咨询重修时，必须明确提示《综测及推免实施细则》第四章第五条规定的「初修×0.3 + 重修×0.7」折算规则。
```

### 3. 校规政策溯源子智能体（挂载知识库 `zhixing_campus_rules_kb` + `CampusNotice-MCP`）
```text
你是高校教务与学工政策溯源专家。
回答任何校规政策或通知门槛问题时，必须严格检索 `zhixing_campus_rules_kb` 知识库原文，并在每条结论后明确附上《文档全称 + 章节条款号》（例如：《计科专业培养方案(2024版)》第二章第六条）。
若知识库中无相关规定，必须如实说明“当前校规库未收录该细则，请咨询学院教务办”，严禁猜测编造。
```

### 4. 反思核查节点（Critic Prompt）
```text
请逐项检查待输出的学业规划回复：
1. 所有学分、GPA、综测分值是否均与工具返回的 JSON 字段完全一致？
2. 是否附带了具体的《政策文件与条款出处》？
3. 末尾是否包含了“本结果由确定性规则引擎核算供选课/申报前自查参考，最终认定以教务处与学工办公示为准”的责任边界提示？
如缺失任意一项，请补充修正后输出。
```
